# Contributing to {{PROJECT_NAME}}

Thanks for helping. Read `AGENTS.md` first: it has the commands, conventions and safety limits.

## How to contribute

1. Open an issue that describes the problem or the proposed behavior.
2. Fork the repo and make a branch.
3. Write a test first, then the change.
4. Run `make check`. Everything must pass.
5. Open a pull request. Fill in every section of the template.

## Rules

- Never commit secrets. A secrets scan runs before each commit and in CI.
- Keep each pull request to one concern.
- Don't change existing tests without explaining why in the pull request.
